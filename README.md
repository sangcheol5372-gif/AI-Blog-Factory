# AI Blog Factory

> "AI Blog Factory는 AI를 활용하여 사람이 직접 운영하는 것보다 더 효율적인 블로그 콘텐츠 생산 시스템을 만드는 것을 목표로 합니다."

## 🛠️ Tech Stack

- Python
- Cursor
- GitHub
- OpenAI API
- Claude API
- WordPress
- Markdown

---

# 🎯 프로젝트 목표

AI Blog Factory의 목표는 단순히 글을 자동으로 생성하는 것이 아니라,
검색엔진에 최적화된 고품질 콘텐츠를 지속적으로 생산하여 장기적인 수익을 창출하는 것입니다.

주요 목표

- SEO 최적화 글 자동 생성
- AI 이미지 자동 생성
- Word(.docx) 저장
- HWP 변환 지원
- WordPress 자동 발행
- Google 검색 최적화
- 장기적인 애드센스 및 제휴마케팅 수익 창출
